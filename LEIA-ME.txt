O DESENHO ESCOLHIDO
-------------------
O TIME continua sendo o CLUBE — um escudo, um responsável, um login. O
que nasce é a INSCRIÇÃO do clube em cada categoria. O Leões FC é um só e
disputa o Sub-11 e o Sub-15.

  championships          → o formato de disputa (igual para todas)
  championships.categories → as regras de cada categoria + a SITUAÇÃO dela
  teams                  → o CLUBE
  team_categories        → o clube disputa esta categoria, neste grupo  ← NOVO
  matches.category_id    → de qual categoria é esta partida             ← NOVO
  players.category_id    → já existia

O grupo (A, B, C…) saiu do time e foi para a inscrição: o mesmo clube
pode cair no grupo A do Sub-11 e no C do Sub-15 — antes isso era
impossível de representar.

A SITUAÇÃO (rascunho / em andamento / encerrado) passa a ser por
categoria, como você pediu: o Sub-11 pode encerrar com o Sub-17 ainda na
semifinal. Categoria sem situação própria herda a do campeonato.

O limite de equipes do plano continua contando CLUBES, não inscrições.
Um clube em quatro categorias é um clube.


O QUE ACONTECE COM O QUE JÁ EXISTE
----------------------------------
Nada é apagado. Todas as partidas e todos os clubes vão para a PRIMEIRA
categoria de cada campeonato — o que é idêntico ao comportamento de hoje.

⚠️ ATENÇÃO se você já tem um campeonato rodando com VÁRIAS categorias:
todos os jogos dele vão para a primeira categoria. Está correto do ponto
de vista dos dados, mas pode não ser o que você queria. O passo 2 traz
uma tela de conferência para mover os jogos para a categoria certa.

Se preferir, confira agora mesmo no SQL Editor:

  select category_id, count(*) from matches
   where championship_id = 'SEU-CAMPEONATO' group by 1;
