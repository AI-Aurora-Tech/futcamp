OS DOIS LINKS
-------------
Na aba TIMES do campeonato, com mais de uma categoria, aparecem:

  🔗 Link para criar time          → ABERTO, para todas as categorias
  🔗 Sub-11  🔗 Sub-13  🔗 Sub-15  → DIRECIONADO, um por categoria

LINK ABERTO: o responsável vê a pergunta "Em quais categorias o time vai
jogar?" com uma caixa para cada uma, e marca as que o clube disputa.
Não dá para criar o time sem marcar pelo menos uma.

LINK DIRECIONADO: não pergunta nada. Mostra "🎯 Este link é da categoria
Sub-13 — o time entra direto nela" e inscreve só nela.

O mesmo conjunto de categorias devolve sempre o MESMO link. Clicar duas
vezes em "Sub-13" não cria dois links vivos para a mesma coisa.

⚠️ A trava está no BANCO, não na tela: se alguém trocar o parâmetro no
navegador para entrar numa categoria que o link não abriu, a inscrição é
recusada. Validar só na tela seria pedir licença para burlar.


ESTRUTURA POR CATEGORIA
-----------------------
No formulário do campeonato, dentro do bloco "⏱ Regras de jogo" de cada
categoria, e só no formato de grupos + mata-mata:

  Grupos nesta categoria    → em branco = como o campeonato
  Equipes por grupo         → cada categoria tem a sua
  Classificados por grupo   → já existia, agora vale de verdade

Assim o Sub-11 pode ter 2 grupos classificando 2, e o Sub-17 ter 4 grupos
classificando 1 — cada categoria com a sua condição, como você pediu.

A FORMA de disputa (pontos corridos / grupos / mata-mata) continua sendo
do campeonato, igual para todas. Campo em branco herda o número do
campeonato: nada do que já existe precisa ser repreenchido.
